# Погода (Open-Meteo) для KDE Plasma 6

[English](README.md) | [Русский](README.ru.md)

[![KDE Plasma 6](https://img.shields.io/badge/KDE%20Plasma-6.0%2B-blue.svg)](https://kde.org/plasma-desktop/)
[![Qt 6](https://img.shields.io/badge/Qt-6-green.svg)](https://www.qt.io/)
[![License: GPL v2+](https://img.shields.io/badge/License-GPLv2%2B-blue.svg)](LICENSE)

Нативный виджет рабочего стола и панели KDE Plasma 6, предоставляющий точный прогноз погоды на базе сервиса **[Open-Meteo](https://open-meteo.com/)**.

---

## ✨ Возможности

- 🌐 **Без API-ключей и регистрации**: Работает сразу «из коробки», без регистрации, токенов и ограничений по подписке.
- 🔍 **Многоязычный поиск городов**: Встроенный геокодинг Open-Meteo находит города, посёлки и регионы на русском и английском языках.
- 🌡️ **Гибкая настройка единиц измерения**:
  - **Температура**: Цельсий (°C) или Фаренгейт (°F).
  - **Скорость ветра**: м/с (метры в секунду), км/ч или мили/ч с 16-румбовым компасом.
  - **Давление**: **мм рт. ст.** (mmHg) или **гПа** (hPa, гектопаскали).
- 📅 **Два режима прогноза во всплывающем окне**:
  - **Почасовой прогноз на 24 часа с дискретной пагинацией**:
    - **Идеальная пагинация по 5 карточек**: Плавная прокрутка ровно по 5 карточек на страницу с сохранением границ и нулевым сдвигом; листание кнопками «Влево» / «Вправо» или горизонтальным колесом мыши / жестами тачпада.
    - **Бейджи «Завтра»**: Карточки следующего дня содержат компактный бейдж «Завтра» («Tomorrow»), а карточка перехода в полночь (`00:00`) выделена акцентной рамкой.
    - **Подсветка текущего часа**: Первая карточка выделена контрастной рамкой для быстрой ориентации.
    - **Подробные метрики часа**: Время, погодная иконка, температура и относительная влажность воздуха (`%`).
    - **Автоматический возврат**: При каждом открытии виджета список автоматически сбрасывается на текущий час.
  - **Прогноз на 7 дней**: Максимальная и минимальная температура, описание условий и календарные даты.
- 🎨 **Интеграция с панелью задач**:
  - Компактный режим панели с отображением текущей температуры и значка погоды.
  - Полная поддержка цветовых тем и оформления KDE Plasma.
  - Возможность скрыть или показать значок погоды на панели.
- 🛡️ **Надёжная работа с сетью, зеркала серверов и восстановление после сна**:
  - **Автоматический переход между зеркалами серверов (Multi-Host Fallback)**: Отказоустойчивое переключение между официальными эндпоинтами Open-Meteo (`api.open-meteo.com`, `customer-api-eu02.open-meteo.com`, `historical-forecast-api.open-meteo.com`) с быстрым таймаутом 3.5 сек на сервер. Гарантирует бесперебойную прямую работу при блокировках отдельных подсетей провайдерами без необходимости включения VPN или настройки прокси. Рабочий сервер запоминается в памяти для мгновенного выполнения всех последующих запросов (~70 мс).
  - **Честные таймауты запросов и сторожевой сброс**: Нативные таймеры QML исключают зависание интерфейса виджета при недоступности сети.
  - **Распознавание выхода из сна / гибернации**: Сторожевой таймер по системным часам определяет пробуждение компьютера и выжидает стабилизации сетевых маршрутов перед отправкой запроса.
  - **Автоматическое обновление устаревших данных**: При открытии всплывающей карточки данные обновляются, если истёк установленный интервал.
  - **Настраиваемый журнал отладки**: Возможность включить подробный лог в настройках виджета (вкладка **«Внешний вид»**), позволяющая отслеживать запросы, переключения между зеркалами и ответы серверов через команду `journalctl --user -u plasma-plasmashell -f`.
- 🌍 **Поддерживаемые языки и расширяемость**:
  - **Интерфейс и поиск**: Полная поддержка русского (`ru`) и английского (`en_US`) языков «из коробки».
  - **Умный поиск городов**: Ввод кириллицей автоматически запрашивает русский индекс геокодинга (`language=ru`), ввод латиницей использует международный индекс с прозрачным переключением.
  - **Добавление новых языков**: Легко добавить локализацию, создав файл в `package/contents/ui/code/locales/` и зарегистрировав его в `I18n.js`. Pull-реквесты приветствуются!

> [!NOTE]
> **Примечание по языкам**: Названия городов латиницей (включая диакритику, например *München*, *Kraków* или *Tbilisi*) работают бесшовно на всех языках. Для поддержки других систем письма (грузинский, армянский, греческий, арабский) достаточно добавить соответствующий модуль локали.

## 📋 Требования

- **KDE Plasma 6** (`plasma-workspace` >= 6.0)
- **KDE Frameworks 6** & **Qt 6** (с модулями `qml-module-org-kde-plasma-plasmoid`, `kirigami`)
- **Инструменты разработки KDE** (`kpackagetool6`, входит в `plasma-sdk` или базовые пакеты разработки)

## 🚀 Установка

### Вариант 1: Автоматический установщик (рекомендуется)

Клонируйте репозиторий и запустите скрипт установки:

```bash
git clone https://github.com/acmodeu/org.kde.plasma.weather.plasmoid.git
cd org.kde.plasma.weather.plasmoid
./install.sh
```

Скрипт установки (`install.sh`) выполняет:
1. **Очистку кэша QML**: Удаляет `~/.cache/plasmashell/qmlcache` и `~/.cache/plasma*` для гарантированной загрузки свежих файлов.
2. **Остановку `plasmashell`**: Корректно завершает работу оболочки Plasma для предотвращения блокировки файлов при установке.
3. **Очистку кэшированной геометрии**: Удаляет устаревшие параметры `popupWidth`/`popupHeight` из `plasma-org.kde.plasma.desktop-appletsrc` от предыдущих ручных изменений размера.
4. **Установку/обновление пакета**: Вызывает `kpackagetool6` для установки или обновления плазмоида в `~/.local/share/plasma/plasmoids/org.kde.plasma.weather.openmeteo`.
5. **Обновление системного кэша**: Выполняет `kbuildsycoca6` для регистрации виджета в базе плагинов KDE.
6. **Перезапуск `plasmashell`**: Запускает оболочку Plasma, делая виджет сразу доступным.

---

### Вариант 2: Установка через графический интерфейс KDE

1. Сгенерируйте архив `.plasmoid`:
   ```bash
   ./pack.sh
   ```
2. Нажмите правой кнопкой мыши на панели задач или рабочем столе.
3. Выберите **Добавить виджеты...** -> **Загрузить новые виджеты** -> **Установить из локального файла...**
4. Выберите созданный файл `org.kde.plasma.weather.openmeteo.plasmoid`.

---

### Вариант 3: Режим разработки (символическая ссылка)

Если вы разрабатываете виджет, создайте симлинк папки пакета напрямую в директорию плазмоидов:

```bash
ln -sfn "$(pwd)/package" ~/.local/share/plasma/plasmoids/org.kde.plasma.weather.openmeteo
kbuildsycoca6
systemctl --user restart plasma-plasmashell.service
```

---

## ⚙️ Добавление на панель задач

1. Нажмите правой кнопкой мыши на панели -> **Добавить виджеты...**.
2. В строке поиска введите **"Weather (Open-Meteo)"** или **"Погода (Open-Meteo)"**.
3. Перетащите виджет на панель.
4. Нажмите правой кнопкой мыши на виджет -> **Настроить: Погода (Open-Meteo)...** для выбора города и удобных единиц измерения.

## 📂 Структура проекта

```text
.
├── package/
│   ├── metadata.json                 # Метаданные плазмоида Plasma 6 (ID: org.kde.plasma.weather.openmeteo)
│   └── contents/
│       ├── config/
│       │   ├── main.xml              # Схема настроек KConfigXT
│       │   └── config.qml            # Модель вкладок диалога настроек
│       └── ui/
│           ├── main.qml              # Главная точка входа и контроллер данных
│           ├── CompactRepresentation.qml  # Вид на панели задач (температура и значок)
│           ├── FullRepresentation.qml     # Всплывающее окно с подробным прогнозом
│           ├── ConfigWeatherStation.qml   # Поиск города и выбор координат
│           ├── ConfigUnits.qml            # Настройки единиц измерения и языка
│           ├── ConfigAppearance.qml       # Настройки внешнего вида
│           ├── icons/
│           │   ├── weather-wind.svg       # Встроенный значок ветра
│           │   └── temperature-normal.svg # Встроенный значок ощущаемой температуры
│           └── code/
│               ├── OpenMeteo.js      # Клиент API и расчёт погоды
│               ├── I18n.js           # Диспетчер локализации
│               └── locales/
│                   ├── en_US.js      # Английская локализация
│                   └── ru.js         # Русская локализация
├── install.sh                        # Скрипт автоматической установки
├── uninstall.sh                      # Скрипт полного удаления
├── pack.sh                           # Скрипт упаковки в архив .plasmoid
├── .gitignore                        # Правила исключений Git
├── LICENSE                           # Лицензия GNU General Public License v2.0+
├── README.md                         # Документация на английском языке
└── README.ru.md                      # Документация на русском языке
```
